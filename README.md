# Primitive Quarry

## Automated Mining Meets Industrial Power

Transform your mining operations with Primitive Quarry - a simplified automated mining solution for Minecraft. This quarry system uses furnace-compatible fuels to power through layers of blocks.

### 🔥 Easy Fueling

- Use anything that you would stick in a furnace
- Built-in fuel capacity means the quarry stores more energy than just what's in the fuel stack
- Won't waste fuel, only consumes fuel while working

## Key Features

### ⚡ Efficient Mining

Mines a configurable area down to bedrock with smart fuel consumption and fun particle effects. Speed is also configurable, can mine up to 1 block per tick.

### 🔍 Smart Filtering

Built-in filter system to ignore unwanted blocks like dirt and gravel. Focus on the resources that matter. Customize your filter settings to match your resource gathering needs.

### 📦 Storage

Internal storage to support reasonable mining adventures - at least enough buffer to get hoppers or some other solution set up. Not an issue with reasonable filtering.

### ⛏️ Tool-Aware

Equip the quarry with a tool and it will use the enchants on the tool to generate the drops. The durability of the tool will not be used. Great use for Golden silk touch pickaxes.

## Technical Specifications

### Core Features

- Adjustable mining area (max 16 block radius)
- Internal fuel storage system
- Tool enchant compatibility (silk touch / fortune)
- Redstone control
- Progress monitoring
- Reset progress with the Handyman's Wrench

### Crafting Requirements

- 3x Planks
- 2x Stone (tag)
- 1x Chest
- 1x Diamond Pick
- 1x Diamond Shovel
- 1x Furnace

## Performance Metrics

- Mining Speed: up to 1 block/tick - configurable
- Fuel Efficiency: 4000 units of fuel per block - configurable

## Installation & Compatibility

- Requires VapourWare for installation
- Optional compatability with Jade and JEI
